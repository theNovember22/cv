## 🎨 Design & Key Highlights

### 1. Apple Human Interface Guidelines (HIG) Color Palette
- **System Colors**: System Blue (`#0A84FF`), Cyan (`#64D2FF`), Indigo (`#5E5CE6`), Purple (`#BF5AF2`), Mint (`#63E6E2`), Green (`#30D158`), Yellow (`#FFD60A`), Orange (`#FF9F0A`), Pink (`#FF375F`), and Red (`#FF453A`).
- **Dark Mode Default**: Deep OLED black base (`#000000`) with ambient radial illumination, frosted glass panels (`backdrop-filter: blur(24px) saturate(190%)`), and translucent hairline borders.
- **Apple Light Theme Switcher**: 1-click toggle to crisp Cupertino ceramic white (`#F5F5F7`) with local storage persistence.

### 2. Abu Said Signature Architecture
- **macOS Interactive Code Card**: authentic Apple traffic light controls (Red, Yellow, Green), syntax-highlighted `developer.js` object, interactive `Run Code` execution tray, and 1-click clipboard copy.
- **Interactive About Me**: High-resolution profile portrait with Apple glowing glass frame, floating experience pill, and metric highlight cards.
- **Experience Timeline**: Modern vertical timeline with glowing Apple nodes covering Infosys (Systems Engineer - SAP BW/4HANA), NIT Goa Placement Coordinator (M.Tech CSE), and Amazon ML Summer School.
- **Skills Infinite Marquee & Category Grid**: Continuous scrolling marquee + category filters (Languages, Backend & Web, AI/ML & Data, Tools & Enterprise).
- **Featured Projects Showcase**: 7 detailed projects (Personal AI Voice Assistant, MovieGo+, Human-AI Active Learning Research, CNN Handwritten Digit Recognition, Interactive Sudoku Solver, BayGrid Smart Parking, National EV Energy Optimization Engine) with filter tabs, tags, and direct GitHub/Live links.
- **Education & Honors**: Cupertino glass cards for degrees and honors (GATE CSE AIR 10139, GATE DA AIR 9572, Infosys Certifications, NCC 'C' Corporal, LeetCode 300+ solved).
- **Direct Contact Hub**: Contact form with mailto generator, direct email, phone, location, and Apple alert toast system.

## 🚀 Local Development & Preview

You can open `index.html` directly in any web browser, or launch a lightweight server:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:8000` in your browser.
